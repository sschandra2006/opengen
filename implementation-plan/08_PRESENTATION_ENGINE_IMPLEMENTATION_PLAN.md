## 1. Engine Scope & Executive Overview

Engine B is OpenGen's dedicated presentation generation system. Unlike web-first platforms (Gamma, Pitch) that flatten complex slide layouts into static raster images or non-editable shapes upon PowerPoint export, **OpenGen guarantees 100% native, editable PowerPoint (`.pptx`) presentations**.

Every text box, table, container card, and chart generated by Engine B is constructed as a first-class Microsoft PowerPoint object that corporate users can edit directly inside desktop PowerPoint, Google Slides, or Keynote.

### Core Capabilities:
1. **Multi-Modal Ingress:** Generates decks from prompts, markdown text, structured DOCX outlines, or PDF source materials.
2. **AI Storytelling & Slide Planning:** Uses fast LLMs (`gemini-2.5-flash` / `gpt-4o-mini`) to structure narratives into slide titles, thesis statements, bullet cards, and quantitative data.
3. **Coordinate Geometry Layout Solver:** Solves exact spatial placement (X, Y, Width, Height) for 1-column hero, 2-column comparison, 3-column feature cards, 4-column metrics, and split layout slides.
4. **Font-Scaling Overflow Guard:** Automatically checks text length against card dimensions and adjusts font sizes dynamically to eliminate text overflow.
5. **Native PowerPoint Excel Charts:** Injects real Office chart objects (Bar, Column, Line, Pie) backed by embedded Excel worksheets (`CategoryChartData`).
6. **Theme & Palette Engine:** Configures corporate brand palettes, background tints, and typography hierarchy across standard widescreen 16:9 slide geometry.
7. **Slide-Level Regeneration:** Allows regenerating a single slide (e.g., slide 4) without altering the rest of the presentation.

## 3. Subsystem Architecture & Detailed Specifications

### 3.1 Subsystem 1: Storytelling Planner & JSON Schema
- **Target Location:** `src/opengen/engines/presentation/planner.py`.
- **Functionality:** Accepts user topic, audience profile, target slide count (default: 8-12), and reference material. Calls the `ProviderManager` with a strict JSON schema.

#### Pydantic Schema (`opengen.domain.presentation`):
```python
from typing import List, Optional, Literal
from pydantic import BaseModel, Field

class MetricCard(BaseModel):
    label: str
    value: str
    change_indicator: Optional[str] = None # e.g. "+24% YoY"

class ChartSpec(BaseModel):
    chart_type: Literal["bar", "column", "line", "pie"]
    title: str
    categories: List[str]
    series_name: str
    values: List[float]

class SlideCard(BaseModel):
    card_index: int
    title: Optional[str] = None
    body_bullets: List[str] = Field(default_factory=list)
    icon_name: Optional[str] = None
    metric: Optional[MetricCard] = None

class SlideSpec(BaseModel):
    slide_number: int
    layout_type: Literal[
        "title_hero",
        "section_header",
        "single_column",
        "two_column",
        "three_column",
        "four_metrics",
        "split_chart"
    ]
    title: str
    subtitle: Optional[str] = None
    cards: List[SlideCard] = Field(default_factory=list)
    chart: Optional[ChartSpec] = None
    speaker_notes: Optional[str] = None

class PresentationDeckSpec(BaseModel):
    topic: str
    theme_name: str = "modern_corporate" # modern_corporate, ocean_blue, warm_editorial, dark_tech
    slides: List[SlideSpec]
```

### 3.2 Subsystem 2: Coordinate Geometry Layout Solver
- **Target Location:** `src/opengen/engines/presentation/layout_solver.py`.
- **Slide Dimensions:** Standard 16:9 widescreen:
  - Width: $13.333\text{ inches}$ ($1,280\text{ pt}$)
  - Height: $7.500\text{ inches}$ ($720\text{ pt}$)
  - Margins: Left $= 0.8\text{"}$, Top $= 0.8\text{"}$, Right $= 0.8\text{"}$, Bottom $= 0.8\text{"}$
  - Available Content Area: Width $= 11.733\text{"}$, Height $= 4.5\text{"}$ (below header)

#### Layout Mathematical Calculations:
1. **Three-Column Card Layout (`three_column`):**
   - Available Width: $W_{\text{avail}} = 11.733\text{ inches}$
   - Column Gap: $G = 0.4\text{ inches}$
   - Card Width:
     $$W_{\text{card}} = \frac{W_{\text{avail}} - (2 \times G)}{3} = \frac{11.733 - 0.8}{3} = 3.644\text{ inches}$$
   - Card Height: $H_{\text{card}} = 4.2\text{ inches}$
   - $X$-Coordinates:
     $$X_0 = 0.8\text{"}, \quad X_1 = 0.8 + 3.644 + 0.4 = 4.844\text{"}, \quad X_2 = 4.844 + 3.644 + 0.4 = 8.888\text{"}$$
2. **Four-Metric Dashboard (`four_metrics`):**
   - Column Gap: $G = 0.3\text{ inches}$
   - Card Width:
     $$W_{\text{card}} = \frac{11.733 - (3 \times 0.3)}{4} = 2.708\text{ inches}$$
   - Giant Stat Font: 44pt Bold; Label: 12pt Regular.

#### Dynamic Font-Scaling Guard:
- To prevent text boxes from overflowing their container cards, `layout_solver.py` measures total text length:
  $$\text{effective\_lines} = \sum_{\text{bullet}} \left\lceil \frac{\text{len}(\text{bullet}) \times \text{char\_width}}{W_{\text{card}}} \right\rceil$$
- If $\text{effective\_lines} \times (\text{font\_size} \times 1.3) > H_{\text{card}}$, font size is automatically stepped down:
  $$18\text{pt} \longrightarrow 16\text{pt} \longrightarrow 14\text{pt} \longrightarrow 12\text{pt}$$

### 3.3 Subsystem 3: Native PPTX Builder (`python-pptx`)
- **Target Location:** `src/opengen/engines/presentation/builder.py`.
- **Implementation Principles:**
  1. **Background & Cards:** Creates rounded-rectangle shapes with subtle borders (`#E2E8F0`) and solid white or soft grey fills (`#F8FAFC`).
  2. **Text Frames:** Sets `word_wrap = True`, margins ($0.15\text{"}$), and paragraph line spacing ($1.15$).
  3. **Native Charts:** Uses `python-pptx.chart.data.CategoryChartData`:
     ```python
     from pptx.chart.data import CategoryChartData
     from pptx.enum.chart import XL_CHART_TYPE

     chart_data = CategoryChartData()
     chart_data.categories = spec.chart.categories
     chart_data.add_series(spec.chart.series_name, spec.chart.values)

     chart = slide.shapes.add_chart(
         XL_CHART_TYPE.COLUMN_CLUSTERED,
         x, y, cx, cy, chart_data
     ).chart
     ```
     This produces genuine Microsoft Excel charts that can be double-clicked inside PowerPoint to edit data points directly.

### 3.5 Subsystem 5: Single-Slide Regeneration
- **Target Location:** `src/opengen/engines/presentation/regenerate.py`.
- When a user asks to "Make slide 3 more concise" or "Change slide 5 to a bar chart":
  1. OpenGen reads the existing deck spec JSON from `diskcache`.
  2. Calls LLM with only Slide 3's context.
  3. Uses `python-pptx` to locate slide index 3, removes old slide shapes, rebuilds new layout shapes in-place, and saves the deck.
  4. Processing time: **< 1.5 seconds**. Cloud token cost: **< $0.001**.
